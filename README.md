# SILAB - Sistem Informasi Pencatatan Kunjungan Laboratorium

## Deskripsi
SILAB merupakan aplikasi berbasis web untuk mencatat dan
mengelola data kunjungan laboratorium.

## Teknologi
- Python Flask
- MySQL 8.4
- Redis 7
- Nginx
- Docker dan Docker Compose

## Arsitektur
Aplikasi menggunakan empat service utama:
1. Web Application
2. Database MySQL
3. Redis
4. Nginx Reverse Proxy

## Menjalankan Aplikasi
Pastikan Docker Desktop sudah aktif, kemudian jalankan:

docker compose up -d --build

Akses aplikasi melalui:
http://localhost:8080
